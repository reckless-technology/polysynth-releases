# Reckless Polysynth

The downloads of Reckless Polysynth, a polyphonic virtual-analog synthesiser: two band-limited oscillators with
detuned voices fanned across the stereo field, a four-pole transistor-ladder filter that sweeps and self-oscillates,
two envelopes, two LFOs, and a hall and modulation after the mix. A VST3, an Audio Unit on macOS and a standalone app.

**No release has been cut yet.** The download table lands here with the first one. Until then there is nothing to
install, and the links below do not resolve.

| | | |
|---|---|---|
| macOS 13.3 (Ventura) or later, Apple silicon or Intel | `reckless-polysynth-macos.pkg` | signed and notarized installer |
| Windows 10 or 11, 64-bit | `reckless-polysynth-win64-setup.exe` | signed installer |
| Linux x64: Debian, Ubuntu, Mint | `reckless-polysynth-linux-amd64.deb` | `sudo apt install ./reckless-polysynth-linux-amd64.deb` |
| Linux x64, any distribution with glibc 2.38 | `reckless-polysynth-linux-x64.zip` | the VST3 and app to copy by hand |

Every release will be listed under [Releases](https://github.com/reckless-technology/polysynth-releases/releases) with
its notes, the user guide and `SHA256SUMS`, each file's checksum. The download page, the user guide and the news are at
[recklesstechnology.com](https://recklesstechnology.com/).

Reckless Polysynth ships on its own, apart from the Reckless plugin bundle at
[plugins-releases](https://github.com/reckless-technology/plugins-releases): it is an instrument rather than an
effect, it is not one of the Pedalboard's chain, and it carries its own version number.

This repository holds the downloads alone — it is written only by the source repository's promotion, never by hand.
The synthesiser is free to use under the end-user licence the installer shows (also at
[recklesstechnology.com/legal/eula](https://recklesstechnology.com/legal/eula/)); it is not open source.
